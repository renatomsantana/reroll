Prompt

Create a highly detailed, fully parametric 3D printable model of a fantasy castle dice tower inspired by medieval architecture. The design must be optimized for FDM 3D printing without requiring supports whenever possible.

Overall Design

The object is a cylindrical castle tower that functions both as a dice tower and dice storage organizer.

The tower consists of several detachable modules:

Main dice tower
Removable top lid
Internal dice ramp system
Bottom rolling tray
Dice storage compartments
Optional removable organizer inserts

The aesthetic should resemble a realistic medieval stone castle with clean brick patterns.

Main Tower
Circular body.
Thick walls.
Exterior covered with offset stone bricks.
Castle battlements (crenellations) around the top.
Large cylindrical hollow interior.
Dice are dropped through the top.

The inside contains multiple alternating ramps positioned approximately every 45–60 degrees.

Each ramp should:

slightly slope downward
extend about 70–80% across the diameter
alternate left and right
include rounded edges to reduce wear
generate random bouncing before exit

The bottom of the tower opens toward the rolling tray.

Top Lid

The lid is removable.

Features:

castle battlements matching the tower
snug friction fit
internal lip for alignment
optional magnet pockets
center opening allowing dice insertion

The lid can optionally include shallow recessed slots to organize one complete RPG dice set:

D4
D6
D8
D10
Percentile D10
D12
D20

Each recess follows the approximate silhouette of the corresponding die.

Dice Organizer

The organizer stores multiple RPG dice sets.

Design compartments using removable honeycomb trays.

Each tray should:

hold one full RPG set
prevent dice from touching each other
be easily removable
stack neatly
Bottom Rolling Tray

The base extends outward forming a semicircular tray.

Features:

raised outer wall
smooth rolling surface
integrated exit from tower
enough space for several dice to stop rolling

Optional:

engraved dragon emblem
compass rose
D20 symbol
medieval ornament
Structural Details

Wall thickness:

2.5–3 mm

Floor thickness:

3 mm minimum

Minimum printable feature:

0.8 mm

Chamfer all sharp internal edges.

Fillet exposed corners slightly.

Brick Pattern

Use realistic medieval masonry.

Bricks should:

vary slightly in size
have recessed mortar lines
wrap seamlessly around the cylinder
continue across the lid

Avoid repetitive textures.

Internal Engineering

Ensure:

dice never become trapped
every ramp has generous clearance
all internal transitions are filleted
dice naturally accelerate downward

Support:

standard RPG dice
oversized resin dice
metal dice
Printing Requirements

Designed for:

FDM printing
0.4 mm nozzle
0.2 mm layer height

No supports inside the tower.

Split into printable modules when necessary.

Flat printing surfaces.

Use alignment pins or keyed joints.

Optional magnet pockets:

6×2 mm magnets
Optional Version

Create a second variant inspired by a wizard tower.

Add:

spiral staircase wrapping around the exterior
observation platform at the top
gothic windows
stone arches
magical rune engravings
slightly taller proportions
same internal dice tower mechanism
Style

The model should look like a premium tabletop accessory suitable for Dungeons & Dragons, Pathfinder, and other RPG systems. It should balance realism, elegance, structural strength, and printability while remaining fully parametric and easy to modify.
